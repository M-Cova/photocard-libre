# Privacy

PhotoCard Libre funziona localmente sul dispositivo e non richiede il permesso o l’accesso a Internet.

- non contiene pubblicità;
- non integra sistemi di tracciamento o analisi dell’uso;
- non richiede registrazione né account;
- fotografie e didascalie vengono elaborate localmente e non sono caricate su server esterni;
- le copie delle immagini, le anteprime e gli altri file temporanei restano nella cache privata dell’app;
- un PDF viene salvato o condiviso soltanto in seguito a una scelta esplicita dell’utente.

Il manifest dell’app non dichiara il permesso `android.permission.INTERNET`.
